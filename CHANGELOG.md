# Changelog

## 1.0.0 - Release candidate

- Added administrator-configured font-family choices for TinyMCE.
- Added capability checks, configuration normalisation, privacy metadata, PHPUnit, AMD, and Behat coverage.
- Added optional integration coverage with `tiny_cceadfontsize`, without making that plugin an installation dependency.
- Declared Moodle 5.1 and 5.2 support and tested PostgreSQL and MariaDB combinations in GitHub Actions.
